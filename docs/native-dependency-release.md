Reusable Intel macOS cryptography wheel with statically linked OpenSSL LTS.

This is a connector build dependency, not an application release or an upstream
cryptography/OpenSSL release. The asset includes its source/build-input
manifest, component SBOM and original toolchain inventory. Its GitHub
provenance must identify this repository's main-branch validation workflow on a
GitHub-hosted runner. Consumers rerun native and vulnerability checks.

See [Intel dependency build](https://github.com/ricardomartins-gravitee/openmaskit-connector/blob/main/docs/intel-wheel.md)
for inputs, verification and reuse policy.
